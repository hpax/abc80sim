Usage: abc80 [options] [[[memspace][@start],]romfile...]

Simulate a microcomputer from the Luxor ABC80/800 series.
Most long options can be prefixed with --no- to negate.

Options (defaults in brackets):
       --abc80             simulate an ABC80 (default)
       --abc800c           simulate an ABC800C
       --abc800m           simulate an ABC800C
       --abc802            simulate an ABC802
  -FS, --server port       run as a PUN80 file/print server
  -LS, --serverlist file   read server ports from a file
  -4,  --40                start in 40-column mode
  -8,  --80                start in 80-column mode (default)
  -b,  --no-basic          no BASIC ROM (uninitialized ROM instead)
       --basic             reverts the --no-basic option
  -d,  --no-device         no device driver ROMs
       --device            reverts the --no-device option
       --no-dos            no disk operating system ROM
       --dos               reverts the --no-dos option
       --no-pr             no printer extension ROM
       --pr                reverts the --no-pr option
  -t,  --trace event,...   trace various events (see "--trace help")
  -Ft, --tracefile file    redirect trace output to a file
  -v, - -version           print the version string
  -h,  --help              print this help message
  -s,  --speed #.#|max     set the CPU frequency to #.# MHz [original]
       --color             allow ABC800C-style color (default)
       --no-color          black and white only
       --magic             enable magic I/O port 184 (default)
       --no-magic          disable magic I/O port 184
  -H,  --headless          run headless (no screen/keyboard support)
  -B,  --batch             quit after scripts have been executed
  -Dd, --diskdir dir       set directory for disk images [abcdisk]
  -Df, --filedir dir       set directory for file sharing [abcdir]
  -Ds, --scrndir dir       set directory for screen shots [.]
  -Du, --dumpdir dir       set directory for memory dumps [.]
  -Cp, --printcmd cmd      set command to launch a print job (see below)
  -Fc, --casfile file      input file for cassette (CAS:)
  -Lc, --caslist file      read list of files for the cassette from a file
  -Dc, --casdir dir        set directory for named cassette files [= filedir]
  -Cs, --scriptcmd cmd     command line to auto-type on startup
  -Fs, --scriptfile file   script file to auto-type on startup
  -Ls, --scriptlist file   read list of script files
  -e,  --console           enable console output device (PRC:)
  -Fe, --consolefile file  enable console output device to a file
  -o,  --output            print text screen on exit
  -Fo, --outputfile        print text screen on exit to a file
       --detach            detach from console (default for --server)
       --initram hex...    initialize RAM areas to a specific value
       --initram random    initialize RAM areas to random content
       --mo# file          mount file as drive MO#: (0-7)
       --mf# file          mount file as drive MF#: (0-7)
       --sf# file          mount file as drive SF#: (0-7)
       --hd# file          mount file as drive HD#: (0-7)

Options for ABC80 only:
  -k,  --kb #              set the memory size K (1-32, 64) [64, 16 with MEG80]
       --old-basic         run BASIC 1.0 (checksum 11273)
       --11273             same as --old-basic
       --10042             run BASIC 1.1 (checksum 10042)
       --new-basic         run BASIC 1.2 (checksum 9913, default)
       --9913              same as --new-basic
       --basicii           run BASIC II (modified ABC800 BASIC)
       --faketype          fake short keystrokes (default > 12.5 MHz)
       --realtype          true key up/down emulation (default < 12.5 MHz)
       --tkn80 none        no 80-character support
       --no-tkn80          same as --tkn80 none
       --tkn80 myab        MyAB TKN80 (video RAM at 22-24K) (default)
       --tkn80 gejo        GeJo TKN80 (video RAM at 30-32K)
       --tkn80 cat         CAT80 (video RAM at 18-20K) *preliminary*
       --nvram[=addr,size] simulate NVRAM at address addr (default 20K,2K)
       --no-nvram	   do not simulate NVRAM
       --meg80[=opt,...]   simulate MEG80 SRAM/flash card
               =flash        start with MEG80 active (flash mode)
               =ram          slot 3 contains SRAM
               =rom          slot 3 is write protected (ROM)
               =#,#...       amount of memory (K) in each slot (8-512) [512]
       --pr=addr           set printer/network ROM base address to
			   28K, 29K, or 30K; 28K is a 2K ROM with
			   additional features *preliminary*
       --smartaid3         load the ROM for Owoco Smartaid III
       --supersmartaid     load the ROM for Owoco SuperSmartaid
       --superbasic        load the ROM for Nyfors SuperBASIC
       --abc80l            load the ROM for ABC80L

Options for ABC800C/M only:
  --hr                     enable high resolution graphics (default)
  --no-hr                  disable high resolution graphics

Options for ABC802 only:
  -Fm, --memfile file      load a file into the ABC802 MEM: device

Option for fileserver only:
       --baud baudrate     set serial port speed [19200]
       --retry[=delay]	   if the port is closed, try to re-open it
       --pidfile file	   write daemon process ID to a file

Fileserver ports can be specified as:

	--server tcp[46][:[hostname][:[port]]
	                   listen on a TCP/IP network socket, optionally
			   restricted to a specific local host name and
			   IPv4 or IPv6 only. The port defaults to 4680.
	--server serial:device[:[baud]]
	                   read from a specific serial port device, optionally
			   with a baud rate specified
	--server fd:rfd[,wfd]
			   read and write from specific file descriptors
			   prepared by the calling process (generally best
			   used with --no-detach.)
	--server device
		           legacy alias for --server serial:device:

	The --server and --serverlist options can be given multiple
	times.

Memory spaces for loading data files or Alt-d data dumps:

	cpu	memory as seen by CPU (default)
	null	discard
	rom	BASIC, DOS, option ROM, printer ROM, etc.; on ABC80 with
		TKN80 loads into both rom40 and rom80 space for the first 16K.
	rom40	40-character BASIC ROM (ABC80/ABC800C)
	rom80	80-character BASIC ROM (ABC80 with TKN80/ABC800M/802/806)
	ram	regular working memory; includes paged-out memory
		ABC80 > 32K, ABC802 etc.
	vram	text video memory
	xmem	extended RAM of any kind (MEG80 for ABC80,
		graphics for ABC800C/800M, MEM for ABC802)
	fgram	fine graphics RAM (ABC800C/800M with HR graphics)
	mem	MEM area of RAM (ABC802)
	sram	SRAM (ABC80 with MEG80)
	flash	Flash memory (ABC80 with MEG80)

The --printcmd command to launch a print job uses the following syntax
to specify the command line arguments:

	*	- replaced by the path to the file to print
	?	- replaced by the name of the printer if any
		  (if the user specified "LIST PR:FOO" this will
		  expand to the string "foo" without quotation marks)
		  This is only available with PUN80 emulation, currently
		  only available on ABC80.
	?{a|b}	- if a printer name is specified, expand to "a",
		  otherwise (meaning ? would expand to the empty
		  string) expand to "b". If "b" is empty the | is
		  optional. This is used to adjust command line
		  options that may depend on if a printer name is
		  present or not, e.g. the -P option to lpr on Unix.


The simulator supports the following hotkeys; the same events can also
be triggered by outputting the equivalent ASCII byte (lower case!) to
"magic" I/O port 184 (unless --no-magic is specified.)

  Alt-d    (100) dump everything available into a directory, atomically
  Alt-f    (102) turn faketype on or off (ABC80)
  Alt-m    (109) dump memory as currently seen from the CPU
  Alt-n    (110) send NMI
  Alt-p    (112) dump primary RAM (64K, even nonexistent)
  Alt-q    (113) quit the simulator
  Alt-r    (114) CPU reset
  Alt-s    (115) take a screenshot
  Alt-x    (120) dump extended/graphics RAM (if any)
